1. What is HTML, and why is it important for websites?

HTML is a language used to create the structure of websites. It is not a programming language, but rather a markup language. It is significant because it serves as the foundation for all websites, all web pages, and all programming languages.

3. What is the purpose of HTML attributes, and where are they written?

The primary purpose of attributes in HTML is to provide additional information, settings, or further specifications regarding an HTML element. These attributes are always written within the opening tag.
